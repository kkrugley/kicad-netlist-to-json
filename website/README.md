# KiCad Netlist to JSON - Web Interface

A web interface for converting KiCad netlist (.net) files to JSON format.

## Features

- Drag & drop file upload
- Convert KiCad netlist files to JSON
- Download converted files
- Minimalist design with Phosphor icons
- Built with Next.js, shadcn-ui, and Tailwind CSS

## Getting Started

```bash
npm install
npm run dev
```

## Deployment

Deploy to Vercel - the configuration is in `vercel.json` in the project root.
